# 相册备份

把安卓手机**系统相册里的全部照片和视频**备份到你选的文件夹（内置存储 / SD 卡 / U 盘），并记录时间信息；恢复后相册排序与原来一致。

## 为什么它不会漏

普通备份软件按文件夹工作（DCIM、Pictures……），照片散落在微信、QQ、截图、下载等目录时必然漏备。
本 App 直接查询安卓的 **MediaStore**（系统媒体库索引）——相册里能显示出来的每一项都在索引里，按索引枚举，一项不漏。

## 下载安装

到 [Releases](https://github.com/SukiSU-rikka/album-backup/releases) 下载最新版 APK 直接安装（Android 10+）。首次使用时授予「照片和视频」权限，并选择一个备份文件夹即可。

## 功能

- **备份到自选文件夹**：用系统文件夹选择器选一次（内置存储、SD 卡、U 盘都可以），之后长期有效。
- **三种整理方式**：备份后的文件可选 按日期（年/月）/ 按来源（相机、截图、微信…）/ 全部平铺，不照搬手机上杂乱的原路径。
- **增量与续传**：已备份的（文件名+大小相同）自动跳过；中途停止后再点备份会接着来，中断时已拷完的文件会被索引收编，不重拷。
- **索引随文件夹走**：`backup_index.json` 就存在备份文件夹里，记录每个文件的拍摄/修改/加入时间与原目录；整个备份文件夹可以整体移动、拷贝到新手机继续用。注意：恢复前不要给备份里的文件改名。
- **恢复还原时间**：读取索引把文件放回系统相册（默认 DCIM/Restored，也可勾选按原文件夹放回），还原拍摄时间、修改时间，相册里按时间排序和原来一致；手机上已有的自动跳过。照片的拍摄地点信息也会随原图一起备份（需授予「媒体位置」权限）。
- **前台服务运行**：备份/恢复在前台服务中进行，带通知进度和唤醒锁，切到别的 App、息屏也不会被系统杀掉。

## 权限说明

「照片和视频」权限用于读取媒体库；「媒体位置」用于备份照片的原始文件（含定位信息），不授予也能备份，只是照片里的拍摄地点可能不保真；恢复通过 MediaStore 写入，不需要全盘存储权限。

## 构建

Kotlin 源码在 `app/src/main/java/cn/rikka/album/`（标准 Gradle 工程，可用 Android Studio 打开）。本仓库的发布包在无 Gradle 环境下用手工管线构建：`kotlinc → d8 → aapt2 → apksigner`，见 `build_album.py`。

## 更新日志

### v1.1.0（2026-10-29）
- 内核整体换新（Kotlin 重写）：备份/恢复改为前台服务 + 通知进度 + 唤醒锁，长时备份更稳。
- 备份整理方式可选：按日期（年/月）/ 按来源 / 平铺。
- 索引改为 `backup_index.json` 并存放在备份文件夹内，备份文件夹可整体迁移；恢复可还原拍摄/修改/加入时间与原图定位信息。
- 注意：本版不再提供 Wi-Fi 传输页；旧版 `manifest.json` 索引与新版不通用（用旧版做的备份，新版无法按索引恢复）。

### v1.0.2（2026-10-22）
- 新增「选择备份文件夹」：可把备份存到内置存储或 SD 卡的任意文件夹（SAF 授权），主界面显示当前备份位置，可一键恢复默认位置。

### v1.0.1（2026-10-22）
- 恢复不再按原路径还原：统一恢复到 Pictures/相册备份恢复，只保留拍摄时间排序；判重也改查恢复目录。

### v1.0.0（2026-10-22）
- 首版：MediaStore 全量枚举备份（增量 + MD5 清单）、Wi-Fi 浏览器传电脑（单文件/ZIP 整包）、按原路径+拍摄时间恢复、备份记录、前台服务保活。
