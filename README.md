# 相册全备份

把安卓手机**系统相册里出现的全部照片和视频**一键备份到本地，再传到电脑保存；需要时按**原目录、原拍摄时间**恢复回相册。

## 为什么它不会漏

普通备份/同步软件按文件夹工作（DCIM、Pictures……），照片散落在微信、QQ、截图、下载等各种目录时必然漏备。
本 App 直接查询安卓的 **MediaStore**（系统媒体库索引）——相册里能显示出来的每一项都在索引里，按索引枚举，一项不漏。

## 下载安装

到 [Releases](https://github.com/SukiSU-rikka/album-backup/releases) 下载最新版 APK 直接安装（Android 8.0+）。首次打开授予「照片和视频」权限即可。

## 功能

- **一键备份到本地**：全量枚举相册所有照片+视频，按原目录结构存入备份文件夹（`Android/data/cn.rikka.album/files/AlbumBackup`），并生成清单 `manifest.json`（原路径、拍摄时间、大小、MD5）。重复备份时未变化的文件自动跳过（增量备份）。
- **Wi-Fi 传到电脑**：点「传到电脑」，手机显示一个地址，电脑浏览器（同一 Wi-Fi）打开即可下载单个文件或整包 ZIP，无需任何电脑端软件；也可以用数据线直接拷备份文件夹。
- **一键恢复**：把备份按原路径写回手机（照片回 DCIM、微信图回微信目录……），恢复拍摄时间并刷新媒体库，相册里的顺序与原来一致；已存在的同文件自动跳过。换新手机时，把备份文件夹拷到新手机的同位置，点恢复即可。
- **备份记录**：每次备份/恢复的时间、成功/跳过/失败数都有记录。
- 备份/恢复在前台服务中运行，切到别的 App 也不会被系统杀掉。

## 权限说明

只需「照片和视频」权限（旧系统为存储权限）；恢复通过 MediaStore 写入，不需要全盘存储权限。

## 构建

无 Gradle 依赖，用 Android SDK 工具链手工构建：`javac → d8 → aapt2 → apksigner`，见 `build_album.py`。
